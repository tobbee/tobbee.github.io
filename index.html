dashcheck

tobbee.github.io/dashcheck

MPEG-DASH conformance checker. Validates the MPD against the schema and the DASH-IF, DVB, HbbTV, CMAF and CTA WAVE rules, parses the segments, and checks live timing against a synchronized clock. The same Go code runs on the command line and, compiled to WebAssembly, in your browser.

  • Go
  • WebAssembly

Open-source work

Libraries and services I write and maintain, at Eyevinn and DASH-IF.

  • mp4ffEyevinn

    Go library and command-line tools for MP4 files, focused on fragmented MP4 as used in DASH, HLS and CMAF. Parses and writes boxes for video, audio, subtitles and metadata, and encrypts and decrypts with cenc and cbcs.

  • livesim2DASH-IF

    DASH live source simulator. Loops VoD assets into endless live streams synchronized to wall-clock time, for testing players with low latency, subtitles, multiple periods and more. Public instance at livesim2.dashif.org.

  • dash-mpdEyevinn

    Go library for MPEG-DASH manifests, based on the XML schema so that every element and attribute is covered.

  • moqlivemockEyevinn

    Media over QUIC test publisher with wall-clock synchronized video, audio and subtitle tracks, plus a subscriber that can pipe the stream to ffplay.

  • hi264Eyevinn

    Pure Go H.264/AVC IDR decoder and bitstream generator, for example to extend fMP4 fragments to a target duration.
